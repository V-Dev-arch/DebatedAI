# Contributing

This repository is the **public face** of DebatedAI (docs, samples, roadmap).

The live application source is not open at this time.

## Ways to help

- Open issues for product ideas, bugs you see on [devtool.freedev.app](https://devtool.freedev.app), or docs improvements
- Suggest frameworks or reviewer UX improvements
- Share feedback on the upcoming **BYOK** (Bring Your Own Keys) feature

## Security

Please do **not** open public issues for security-sensitive reports.  
Contact the maintainer privately via the profile on GitHub.

Thank you for helping make DebatedAI better.
